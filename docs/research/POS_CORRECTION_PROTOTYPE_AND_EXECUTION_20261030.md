# 无教师分数三域校正：兼容原运行的开发方案

## 当前状态和边界

本文件对应独立离线数值原型，**不是完整的可运行实验流程**。现有无教师分数运行的 BND 仅输出诊断，仍要求复核；此原型不实现旧版 BND 仲裁或实际改分，也不将 NEG 当作错误答案。校正候选均不授权自动发布。POS 盲复评分的调用边界已有原型，但批量采集、可验证的数据投影、分学生交叉拟合、仲裁门禁和最终评价仍需独立实现并验证。

另一个实验电脑的 `lf45_co3ind_20261029_v1_calibration` 有未完成的原运行。其清单绑定提交号、受 Git 跟踪的 Python/提示文件及环境。不要修改其清单，不要更新该工作目录后声称可用新代码继续同一清单，也不要删除已保存作答。需要并行开发和同步时使用独立分支/工作区，等原运行结束或明确建立有完整来源记录的迁移机制后再集成。本原型当前是未提交的新文件，不改变现有受跟踪文件。

## 数据边界

拟合输入只能是研究者独立审计并投影的数值：题目、作答标识、POS 路由、评分项标识、满分、原始评分、盲复评分。不能输入教师分数、教师审核结果、派生质量策略，或把教师数据改名为盲复评分。程序只校验字段格式，并**不能证明**数值来源、盲评过程或图片/参考答案来源是否无教师标签。不要把身份信息或 API key 写入输出。

盲复评分应独立重读可用作答、题目与固定准则，不提供该作答基础分、探测分、原路由或教师标签。`label_free_pos_blind.py` 提供可注入的盲评分调用边界，筛选 POS 后只将题目白名单和图片参数传给评分函数；该边界无法审计文本内容或模型是否共享偏差。批量收集代码和来源哈希链尚未实现，不能把人工构造的测试数据当作真实校正数据。

## 本原型实现

`label_free_pos_correction.py` 对 POS 评分项计算 `(blind_score - base_score) / max_score`，在题目与评分项内平均并按 `n / (n + shrinkage)` 收缩、限幅。缺少校正组或少于 `min_count` 时回退零修正；零满分项不参与除法。采用同一题目一致的评分项和分值检查。适用目标可为 POS/BND/NEG，路由保持不变，BND 和 NEG 强制保留复核，所有域仅输出候选分。候选针对原始基础分，**不是仲裁后的核心分**。原型禁止将同一 `(question_id, answer_id)` 同时用于拟合与应用；尚未实现按学生分组的交叉拟合与传导性批次适配。

`scripts/run_pos_correction_prototype.py` 提供 `fit`、`apply`，只处理显式提供的 JSON 数值投影；不调用 API，输出采用独占创建，不覆盖已有文件。拟合摘要的 SHA-256 可检测意外修改，不是数字签名，也不能认证数据真实性。

输入格式举例（纯模拟分数；非项目实验结果）：

```json
{"records":[{"question_id":"Q1","answer_id":"A1","route":"POS","items":[{"item_id":"s1","max_score":5,"base_score":3,"blind_score":4}]}]}
```

应用输入不含 `blind_score`，且身份不得属于拟合集合：

```json
{"records":[{"question_id":"Q1","answer_id":"B1","route":"BND","items":[{"item_id":"s1","max_score":5,"base_score":3}]}]}
```

`min-count`、`shrinkage`、`cap` 都必须在命令中明确提供，不能将示例数值视为最优值。若将真实材料导入原型，应先建立独立、不可变的来源清单，校验题目、评分准则、评分项和参考版本一致，记录学生分组及各输入哈希。

## 后续执行顺序和验收条件

1. 解决原运行的 JSON 返回故障并保留原有检查点；独立确定原运行能否按原源码完成，禁止静默跨源码续跑。
2. 确认并冻结已完成的校准数据，统计每题 POS 数量与评分项覆盖率；保存来源清单，不读取教师标签。
3. 开发独立盲复评分采集器：严格隔离原分及路由，只传题目、准则与作答；每一输出绑定原输入快照、独立调用配置和源检查点哈希；先 mock 测试，再核验智谱文本与视觉最终请求地址均为 Coding Plan。无有效凭证或来源不明时失败关闭。
4. 开发检查点到数值投影的只读适配器，校验原始检查点摘要、题目评分项、盲评对应关系和独立调用协议；不可接受教师标签字段。缺失或无效的盲评不计入拟合，并报告覆盖率和原因。
5. 开发真实分学生交叉拟合或使用不同学生划分的归纳评估；同一学生跨分组也要避免泄露。预先锁定参数、组小样本回退、成本和调用预算。当前 345/45 每题平均只有约 7.7 个校准样本，POS 更少，不保证足够。
6. 单独审计旧版 BND 仲裁、门禁和参数的教师分数依赖；满足边界后建立新的可追踪仲裁器。研究 POS 校正接在仲裁前后的差异，并阻止证据冲突及重复改分。未经验证，不自动放行 BND/NEG。
7. 在未读教师分数前冻结 POS-only、POS+NEG约束和等预算对照的配置与结果。教师分数只在最终评估阶段读取，比较误差、QWK、分域风险、覆盖率、退化率、复核与模型成本。历史探索过的 test 不声称是全新独立留出集。
8. 有足够实验依据后再讨论归档旧监督文件。禁止在此之前删除或改写教师审核资料、旧实验代码和结果。

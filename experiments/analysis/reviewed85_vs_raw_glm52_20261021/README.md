## 解释

1. 排除48份测试作答，旧预测MAE从1.254047降至1.199682；这48份作答的旧最终分MAE约4.28375。这个变化包含评估样本组成的变化，不代表模型能力凭空提高。
2. 再修正14份测试标签，旧预测MAE降至1.190935。对旧最终分而言，12份更接近新标签，1份更远，1份误差不变，总绝对误差减少23.4分，摊到2675份仅减少0.008748。
3. 本轮重新运行MAE为1.201092，比同样本同标签的旧预测高0.010157；宏平均QWK高0.9569个百分点，NMAE略低。不同指标没有一致支持大幅提升。
4. 相对于旧原口径，本轮最终MAE下降约4.22%；不能把这全部归因于审核，或把样本筛选等同于能力提升。
5. 冻结审核85/3411=2.49%，3326份仍未审核。测试改变48份排除及14份修正，仅占原2723份约2.28%；验证集排除4份且没有修分，校准集排除5份、修分1份，影响范围有限。
6. 没有重新训练模型权重。变化通过准则重选、验证集校准和标签评估产生；26题优化准则变化、代码版本和推理随机性均属于混杂因素。
7. 审核的目标是更可靠的标签与结论，独立确认的标签修正不保证任何模型的指标一定上升；不应按模型是否得益决定保留或排除。

## 同口径的新旧差异不确定性

在相同2675份作答、相同审核标签上，以题目为簇进行2000次配对bootstrap，seed=20261021。
- MAE减少量（旧－新）：-0.010157；95%区间[-0.054084, 0.038254]。
- 宏平均QWK变化（新－旧）：+0.9569个百分点；95%区间[-1.5482, 3.4113]个百分点。
- 两个区间均包含0，目前不足以认定本轮重新运行显著优于旧预测；该区间也不是审核因果效应的置信区间。

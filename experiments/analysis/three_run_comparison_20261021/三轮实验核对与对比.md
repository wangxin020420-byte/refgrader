# 三轮实验核对与结果对比

本报告仅离线读取已有文件，不重新评分或校准。

当前优化准则与初始准则均为45题、2675份测试作答；旧实验为45题、2723份。初始准则指标来自终端打印值，QWK由打印的逐题值汇总，均为近似结果。

## 一致性核对

已验证本机保存的消融快照来自主实验：93份数据/初始准则/划分文件与主实验冻结指纹一致；3442份图像资产指纹记录一致；审核决定、样本政策、选择名单逐字节一致。评分核心及提示文件符合消融源码合同，两套校准入口的默认超参数一致。

两轮分别在各自验证评分结果上校准，阈值、风险模型、基础分选择、BND动作门禁、残差校正项可以不同。初始准则实验使用独立OCR/证据缓存，缓存内容未逐份比较。跨机环境变量、实际安装依赖、实际生成配置及逐份测试ID，尚缺另一台电脑的运行文件核对；不能声称所有实际参数完全一致。

固定超参数：BND预算0.60、人工预算默认0.60、NEG预算0.35、top-k=8；残差最小组数20、方向保护最小数3、收缩k=8、校正上限min(2分,0.12M)；conformal coverage=0.90、scale floor=0.05；安全容差max(0.50分,0.10M)，BND/NEG/unsafe-POS成本0.02/0.10/1.00，unsafe-POS上限0.10，BND动作门禁最小数3。预算用于验证集搜索，非测试集比例保证。

## 解释与边界

单次评分取多次探测中的首个评分，不是额外调用的一次独立实验。三支决策后为three_way_core_score，不含残差校正；残差校正后为final_calibrated_score。

旧实验QWK按保存的summary.json逐题重算，可能不同于早期PPT手工表格；没有全局QWK数值，不补填。旧实验数据和执行版本均有差异，不是干净的准则消融对照。

初始准则实验最终MAE较优，但更多调用BND（1675 vs 1151）；优化准则在均值和Core阶段宏QWK略高。尚不能断言优化准则稳定有效或稳定无效。跨机逐份数据配对、配置核对和统计检验完成后，才能进行严格归因。

# SCALE 学校服务器复现方案

日期：2026-09-09。阶段：准备完成后等待论文材料和服务器环境；尚未训练。

## 1. 目标与完成标准

先复现 SCALE，再与 RefGrader 进行同数据对比。第一阶段不修改三支决策。
完成标准不是脚本启动，而是：固定数据/实现/模型版本，完成论文协议检查、训练和评估，保存逐样本预测，解释与论文数字的差异，并输出可重复计算的对比表。

官方来源：
- DOI：https://doi.org/10.1109/TKDE.2026.3673734
- IEEE：https://ieeexplore.ieee.org/document/11433809/
- 作者公开数据：https://github.com/aleversn/SAS-Datasets
- 数据提交：9e1a866d58edaa0d78af374d2f3529a10d72239a

已确认数据仓库，不等于已确认完整训练实现。本次检查作者公开仓库及若干语义模型 README，没有取得明确关联本论文的完整 SCALE 训练入口。GCSE 是另一篇工作，不能直接改名为 SCALE。IEEE 页面目前无法直接取得正文。需要最终版 PDF、补充材料和作者代码信息；没有官方代码时只能在完整方法细节齐备后进行标明身份的独立重实现。

## 3. 依次执行的阶段

| 阶段 | 操作 | 产物/验收 |
|---|---|---|
| A 准备 | 在服务器运行准备脚本，创建目录与工作区，核对数据包哈希 | data_audit.json；原始文件逐文件 SHA256；可重复执行 |
| B 环境 | 运行 inventory-only，确认 GPU 型号/显存/驱动/磁盘、调度器 | server_inventory_*.json；确认是在获准计算节点上训练 |
| C 协议 | 获取最终 PDF、官方代码、模型和超参数，逐项填写 PROTOCOL_CHECKLIST | protocol-lock 与代码/模型/数据版本；区分严格复现和适配复现 |
| D 实现 | 在 env 下独立配置训练环境；按实际 CUDA 与作者要求安装依赖 | 环境锁、训练/评估入口及参数帮助；不改变主项目环境 |
| E 冒烟 | 先检查导入/路径/指标，再用训练集内的小子集完成一个训练—保存—加载—评估循环 | 有效预测、稳定 ID、恢复训练一致性；不用完整实验检查低级错误 |
| F 原论文复现 | 优先 ADS，再 ASAG，随后 LE/SR；先全量设置，再论文规定的少样本设置 | 每种设置的 r/QWK/RMSE、原始分与归一化分记录、训练成本和逐样本预测 |
| G 公平对比 | 在同一原始测试集合比较 SCALE 与 RefGrader；统一标签/满分/指标 | 同协议对比表、分题目误差、配对置信区间、失败样本报告 |
| H 三支审查 | 冻结 rubric、证据与三次评分结果，比较 single/avg/3WD-Core/残差 | POS/BND/NEG 覆盖、严重误判、BND净收益/变差率、真实人工成本 |

阶段 A/B 现在可执行。C 的材料不足，因此不伪造 D/F 的训练命令。得到材料后先补真实训练入口，再按 E/F 执行。

## 4. 数据协议与已发现问题

| 数据 | 固定文件总数 | 训练/测试 | 标签 |
|---|---:|---:|---|
| ADS | 1582 | 1107/475 | 原始标签 0..10，15题 |
| ASAG | 629 | 440/189 | 原始标签保留，21题；README写630 |
| LE | 585 | 409/176 | 原始标签保留，100题 |
| SR | 331 | 231/100 | 原始标签保留；参考答案ID不冒充题目ID |

ADS 子目录说明写80/20，但实际文件和生成脚本是约70/30。根说明称0..1而ADS原始数据是0..10。不得依说明静默改分、重新打乱或补造缺失记录。data_audit.json 记录实际标签范围、内容重复和分区一致性。官方文件划分是否就是 TKDE 最终协议，仍需全文/作者确认。

原论文复现轨道保留官方数据原样；如果出现跨分区重复，不静默删除。另建去重敏感性分析轨道，固定移除 ID，所有对比模型用同一清单。不能把随机答案划分称作未知题目泛化。

本次实际审计：ADS train/test完全相同整条记录的多重集交集计数为41；按同组ID+原样答案文本计数为45。ASAG同组同答案为7，SR同参考ID同答案为1，LE为0。这里是两边出现次数较小值的合计，不等同于唯一文本数，也不包括模糊近重复。它们是公开文件的审计事实，不证明最终论文使用了同一划分。

原始训练分区没有单独验证集时，优先采用论文协议；若必须另划验证集，应从训练分区划出并记录为适配协议，不能用测试分调参。

## 5. 方法与实验约束

模型/超参数以最终论文为准，不预先指定未经核实的 BERT/ERNIE 版本，也不擅自把数据增强大模型换成 GLM。若原 API 不可用，可另列替代模型适配复现，不能称为原论文数值的严格复现。

数据增强仅使用当前训练分区允许的信息。教师测试分不得用于 rubric 优化、阈值选择、残差拟合或样本筛选。对比时需明确各方法获得多少带标签训练数据；监督训练与提示评分的资源差异单独列出。

正式实验必须先写不可变 manifest，至少包含：run_id、协议身份、数据提交/哈希、split ID、代码提交、checkpoint revision、模型/API返回身份、全部参数、种子、指标版本。建议同一逻辑运行使用 runs/<protocol>/<run_id>，断点续跑复用该目录。已完成阶段不重跑，除非输入改变。

原论文指标 r、QWK、RMSE 的标签映射、取整、裁剪必须核实后锁定。补充 MAE、偏差、严重误差率、按题宏平均及配对bootstrap置信区间。多个题目上优先按题聚类重采样；不能拿不同分制的RMSE直接比较。

预测至少保存 sample_id、question/group_id、split、gold_raw、prediction_raw、score_scale、seed、run_id。RefGrader另外保存single/avg/3wd_core/final、域标签、仲裁前后分与成本。样本关联必须通过稳定ID，不依赖排序位置。

三支决策优化放到对比和失败分析之后：固定基础评分，以相同成本/覆盖预算比较无路由、随机路由、简单阈值和A3WA。分别报告自动仲裁次数与真实人工复核次数，自动仲裁不是人工工作量。

## 6. 资源与运行方式

准备脚本只需 Python >=3.7 标准库，不安装深度学习依赖、不占GPU、不调用收费模型。
训练耗时/显存暂不估计：待GPU和模型明确后，用单batch/短epoch实测外推并记录依据。
若学校使用 Slurm/PBS，正式训练在分配的计算节点执行；若允许独占交互GPU，用指定设备并记录。tmux只能保持终端会话，不能替代作业调度或GPU授权。
后续训练环境建在scale/env，下载缓存限定在scale内部或学校指定位置；API密钥只通过环境变量配置，不写进工作区或归档。

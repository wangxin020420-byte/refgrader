# 无教师分评分输入：上游差异审计

本报告是只读诊断，不证明上游问答、参考答案与目标教师评分无关，不读取教师评分文件，也不进行模型调用。对比对象为本机 CSBench 副本的 `question/*.json`（仓库提交 `3531732`）和本项目已准备的 45 道题。

运行：`python scripts/audit_label_free_official_inputs.py --dataset-root <CSBench目录> --prepared-dir data/csbench`。工具对比题干、评分项 ID/描述/分值/参考文本以及参考图片 SHA-256，不输出学生作答或教师评分。

本次结果：45 道题的题干文字一致；`CO_1`、`CO_3`、`CO_4` 的评分项核心内容与当前 CSBench 副本不一致。`CO_1` 当前项目准则由上游的一项 5 分拆为三项；项目 Git 提交 `922a8221` 包含该变化。差异不等同于证明目标分数泄露，但不应把项目版本直接称为未修改的原始准则。

`CO_3` 当前上游参考答案包含“教师评分口径”字样，CSBench Git 提交 `a5ad706` 引入该表述；当前已准备的题目参考文本与该本机副本相同。该关键词本身不能证明使用了目标教师分数，但需要独立溯源；不存在关键词也不能证明独立性。注意，本机 CSBench 的 `origin` 与提交历史均不能单凭仓库名证明它是未经修改的官方基线。

`DM_3` 在本机 CSBench 副本中有两张不同的参考答案图，当前已准备目录仅有一张，SHA-256 对比显示一张源图未匹配。当前开发评分入口按题目查找至多一张参考图，因此不能作为 `DM_3` 完整输入。

现有 `CO_1` 和 `CO_12` 开发结果必须保持为历史运行；切换输入来源、修正评分策略或修复图片处理都需要新的代码和运行 ID。正式无教师分实验仍未就绪，不应根据此报告自动选择或修改阈值。
